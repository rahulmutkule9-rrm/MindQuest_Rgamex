# MindQuest Arena

## Local run
```bash
npm install
npm run build
npm start
```
Open http://localhost:3000

## Render
- Build: `npm install && npm run build`
- Start: `npm start`
- Health: `/health`
- Set `GEMINI_API_KEY` in Render for Gemini-powered evaluation/generation. The app has local fallbacks when the key is absent.
